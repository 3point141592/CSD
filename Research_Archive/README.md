# Research files

This folder contains selected scientific code, configurations, results, file indices and figure inputs. The complete research archive provides the saved model checkpoints, task arrays and detailed execution records required for the full reproduction workflow.

Paths in the indices are relative to the complete archive. References to `../01_Journal_Files` identify the accompanying journal package; equivalent journal files are under `paper/` in this repository.

The [reproduction guide](../docs/reproduce.md) explains the figure workflow available in this repository and the saved-record analyses that require a fresh working copy of the complete archive. Original result rows are retained. Repository file sizes and SHA-256 hashes are recorded in `../docs/file_hashes.csv`. The full archive preserves the source-code versions used for the original experiments and their recorded hashes.
